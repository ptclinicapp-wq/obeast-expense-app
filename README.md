# ลงตัว - บัญชีคู่ของเรา

เว็บแอปจดค่าใช้จ่ายสำหรับสองคน เช่น เปาและติม เน้นกรอกเร็ว เปิดมาก็ใส่ยอดได้ทันที และข้อมูลเก็บอยู่ในเครื่องของผู้ใช้

## สิ่งที่ทำได้

- ใส่ยอดค่าใช้จ่ายพร้อมวันที่และเวลาปัจจุบันโดยอัตโนมัติ
- แก้วันที่และเวลาเองได้
- เลือกได้ว่าเป็นรายจ่ายของเปา ของติม หารครึ่ง หรือแบ่งจ่าย
- โหมดแบ่งจ่ายสามารถแตกยอดย่อยว่าใครรับผิดชอบอะไรเท่าไหร่
- เลือกหมวดค่าใช้จ่าย เช่น อาหาร เดินทาง ของใช้ บ้าน บิล สุขภาพ และอื่น ๆ
- สรุปยอดรายเดือนว่าใครต้องคืนใคร
- เก็บข้อมูลไว้ใน localStorage ของเบราว์เซอร์

## รันในเครื่อง

ต้องมี Node.js 22.13 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิด `http://localhost:3000`

บน PowerShell ถ้าเจอ policy บล็อก `npm.ps1` ให้ใช้:

```powershell
npm.cmd run dev
```

## ความเป็นส่วนตัว

แอปเป็นแบบ local-first ข้อมูลค่าใช้จ่ายอยู่ในพื้นที่ของเบราว์เซอร์บนเครื่องที่ใช้งาน ไม่มีระบบล็อกอินและไม่มี API key ใน repository
